# Code of Conduct

## Our standard

Participants in this project are expected to treat each other with respect, assume good faith, give actionable technical feedback, and protect private information shared during debugging or security reports.

Unacceptable behavior includes harassment, discrimination, threats, deliberate disruption, publishing private information without consent, and submitting malicious code or credentials.

## Enforcement

Report conduct concerns privately to **alex@gladkov.dev**. Include links or other context when safe, and avoid forwarding private credentials or device data.

The maintainer may remove comments, reject contributions, restrict participation, or take other action needed to keep the project safe and constructive.
